Boury. es una plataforma de **E-commerce Frontend** desarrollada con **React.js** y **Firebase**, diseñada para la gestión de productos, carrito de compras y finalización de pedidos. Este proyecto es una Single Page Application (SPA) optimizada para ofrecer una experiencia de usuario rápida y profesional.

---

## 🚀 Funcionalidades Clave
* **Arquitectura SPA:** Navegación fluida sin recarga de página mediante *React Router*.
* **Base de Datos en Tiempo Real:** Gestión de productos y persistencia de órdenes con *Firebase Firestore*.
* **UI/UX Moderna:** Diseño responsive construido con *Tailwind CSS* para una apariencia profesional en dispositivos móviles y escritorio.
* **Carrito Interactivo:** Lógica de carrito gestionada mediante *Context API* con feedback en tiempo real.
* **Validación de Checkout:** Formulario dinámico para la captura de datos del comprador.
* **UX Notifications:** Notificaciones de éxito/error mediante *React Hot Toast*.
